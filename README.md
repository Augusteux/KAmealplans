
<h1>KA Meal Plans</h1>

<h2>This webapp is used to assist cx with choosing a subscription plan and keep them on track</h2>

<h3>CX Profile:</h3>
<ul>
<li>Determine cx gender, weight, height, weight goals, calorie allowance, and macros to determine suitable meal plans</li>
<li>Subscription type and time (days) remaining</li>
<li>Delivery time/schedule</li>
</ul>

<h3>UI Color Motif:</h3>
<ul>
<li>Buttons: red/orange</li>
<li>Price tags: orange or yellow</li>
<li>Meal photos: warm lighting + brown/wood backgrounds</li>
<li>Background: cream, never stark white</li>
</ul>
