# KAmealplans
Website for Kyle and Alyssa's meal plan business

KA Meal Plans

The webapp is used to assist cx with choosing a subscription plan and keep them on track

CX Profile:
-Determine cx gender, weight, height, weight goals, calorie allowance, and macros to determine suitable meal plans
-Subscription type and time (days) remaining
-Delivery time/schedule

UI Color Motif:
Buttons: red/orange
Price tags: orange or yellow
Meal photos: warm lighting + brown/wood backgrounds
Background: cream, never stark white
